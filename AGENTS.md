# GRVTY Project Instructions

You are building a mobile prototype.

Tech Stack:
- Expo React Native
- TypeScript

Primary Goal:
Validate daily engagement for U12 ski racers.

Important:
- Simplicity over completeness.
- Build only MVP features.
- Avoid premature backend work.
- Use mock data unless explicitly asked.

Current MVP Screens:
1. Home Mountain
2. Daily Missions
3. My Racer
4. Rope Team
5. Weekly Story

Brand:
GRVTY - Gravity Racing Team

Motto:
One Team. One Force. For Glory.

Design Principles:
- Feels like a ski racing game.
- Large touch targets.
- Children aged 10-12.
- Positive motivation.
- Cooperation over competition.

Do not add:
- Payments
- Ads
- Social feeds
- Complex authentication
